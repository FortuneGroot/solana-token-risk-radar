# Security

Fortune On-Chain Radar is read-only. There is no wallet, signing, transaction, trade, custody, or fund-transfer code. Never add seed phrases or private keys. Keep `.env` secret and rotate exposed tokens immediately.

On-chain risk data is incomplete and providers can be wrong or unavailable. “Not detected” is not a safety guarantee. Missing information reduces confidence; confirmed blockers override scores. Use minimum Discord permissions, a dedicated production RPC endpoint, API quotas, encrypted off-site backups, OS updates, and one running bot instance.
